# 心理会话记录 · 模板

> 每次有分量的会话复制本模板存为 `YYYY-MM-DD_主题.md`。用于跨会话连续性与模式追踪。内容私密，不外传。

---

- **日期**：YYYY-MM-DD
- **同步 / 数据新鲜度**：`[Heart 同步] OK/WARN` 摘要；若 WARN，写明聚合上下文日期或缺失原因
- **Notion 动态真值（交易/资产相关才填）**：已读 / 未读；当前是否 `持仓中`；若未读，说明原因并降级信心
- **风险等级**：无 / 关注 / 需专业评估 / 紧急
- **关联议题**：（`../议题追踪.md` 里的 `T##`；新开的议题在那边建条目并回填编号）
- **触发情境**：（什么事/什么状态引发的，放回真实生活坐标）
- **核心议题**：（把模糊情绪命名为可处理的问题）
- **识别到的模式**：（对应 `阶段心态地图.md` 的哪条；是清醒痛苦还是失调信号）
- **用的方法**：（流派 + 为什么选它）
- **✅ 事实 / 🔸 推测**：（分离记录，推测待他确认）
- **留给他的练习 / 下一步**：（可执行、可掌控）
- **跟进约定**：（下次何时跟进 / 是否转介）
- **信心**：高 / 中 / 低 / 未知

> **写完别忘收场**：回到 `../议题追踪.md` 更新活状态（开新议题 / 更新进展 / 合上已解决 / 记跟进到期日）。不更新，下次开场就读不到——闭环就断了。
